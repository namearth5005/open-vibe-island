Turn 4 · Asset production kit

4ageneration spec — image model + video model
I can't run image or video models from here — this spec is written to hand to one (or to a designer with real paper). Everything in it is measured off the design system, so any model that follows it lands on-system.
still plates — image model, one prompt per mood
A cat cut from torn black paper (#221f1c), one flat mass, no shading, no fur rendering, ragged fibrous white-paper edge showing tan backing paper (#b3956a) at the tear. Two crayon marks only: a closed-eye arc and one dot, chartreuse crayon (#c9cc4e). Silhouette: [MOOD — sitting upright, loaf, stretched tall…]. Flat collage style, children's book, no gradients, no outlines. Isolated on pure white for matting. 2048px.
· 12 plates: 6 moods × dark + light body (light swaps #221f1c→#f0ead6, marks→#97923f)
· same seed / character reference across all 12 — the animal must read as one animal
· matte to true alpha (luminance key off the white), keep the fiber halo semi-transparent
· reject: gradients, fur texture, pupils, whisker clusters, more than 5 interior marks
motion — video model, per loop, from the still plate
Animate this paper-cutout cat in stop-motion collage style: the whole body bobs gently as one rigid piece (~3.5s loop), tail sways (~3s), one slow blink. The torn edge must NOT boil or redraw between frames — the paper is a physical object. Camera locked. 4s seamless loop, flat background for keying.
· one loop per mood; export frames → sprite sheet or APNG, ~12fps is plenty for stop-motion feel
· fallback if the video model boils the edge: animate the still plate rigidly in code — the 3a rig's transforms applied to the raster
· pill never gets video: baked 28×32 light-body PNG per mood, flat, no halo
The likeliest failure mode is the model over-rendering — fur, shading, expression. The spec's reject list is the quality gate; flat mass is the style.

3bthe stack, exploded
1 flat mass
2 torn edge
3 tan core
4 marks
5 motion — bob · tail · blink
Three layers per plate — tan core (coarse tear, scaled 1.06), the mass (fine tear), marks on top. The displacement seed is locked so the edge is a material, not a flicker. Motion never touches the edge: the layers move as one rigid group.
Marks stay crisp — only the paper tears. A value + saturation jump (#f0ead6 body, #97923f marks), never a hue clash.
3cthe ship pipeline — plates, not rigs
1Paint the animal once in real media — ink and torn paper, one flat mass per mood. Six silhouettes, not six expressions.
2Scan at 3× and cut per-mood plates keeping the true fibrous alpha. Keep the warm tan backing as its own layer.
3Rig three layers — core, mass, marks — plus the tail as its own plate. That is the whole skeleton.
4Idle loop is rigid transforms only — bob 3.4s, tail 2.9s, blink ~6s. The torn edge itself never animates; animated tearing reads as boiling.
5Mood change is a plate crossfade, 160ms, only at rest — never mid-decision, never mid-scroll.
6The pill gets pre-baked 28×32 light-body PNGs — no filters, no shading. Flat mass survives downsampling; rendered fur does not.
dev stand-in until plates land: the seed-locked turbulence rig in 3a — same layers, same timings, swap-in-place. if the loop ever outgrows transforms, Rive with raster meshes — never crisp vectors.
