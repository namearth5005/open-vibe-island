# Geode Phase 0–1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a procedurally-generated crystal in the closed island pill that grows while an agent session runs, freezes and desaturates when the session blocks on the human, sets on clean completion, and fractures on interrupt.

**Architecture:** All crystal logic is a pure, `Sendable` reducer over `AgentEvent` in `OpenIslandCore` (`GeodeState`), mirroring the existing rule that `SessionState.apply(_:)` is the single source of truth. Geometry is derived from a stable hash of `sessionID` and never persisted. `OpenIslandApp` adds a new `IslandRightSlotContent` case and a SwiftUI shape renderer; no existing right-slot behaviour changes.

**Tech Stack:** Swift 6.2, SwiftUI + AppKit, Swift Testing, macOS 14+.

## Scope

This plan covers **Phase 0 and Phase 1 only**, from `docs/superpowers/specs/2026-07-30-geode-session-crystals-design.md`.

Phase 0 is a **kill gate**. Phases 2 (shelf, persistence, back-fill) and 3 (rarity rules, vein strip) get their own plans *after* the gate passes, because detailed steps written now would be discarded if it fails.

**Execution order is Task 1 → Task 0 → Tasks 2–6**, not the order the tasks appear. Task 0 is the gate but it depends on Task 1's geometry to render. See the note at the top of Phase 0.

**One spec property is deliberately deferred:** the spec lists **clarity** (reduced by stall count and mean gate latency) under Crystal Form, but clarity depends on `qualityScore`, which the spec's own build order places in Phase 2. Phase 1 therefore tracks `stallCount` — the input clarity needs — without rendering it. This is a known, intentional gap, not an oversight.

## Deviations from the spec (deliberate, recorded)

1. **Size budget is ~18–20pt, not 22pt.** `Sources/OpenIslandApp/Views/V6NotchContent.swift:91` documents a "~20pt" internal vertical budget for the pill, and grid cells are 8pt. The legibility gate is therefore *stricter* than the spec assumed.
2. **Phase 1 audio reuses `NotificationSoundService`** (system sounds from `/System/Library/Sounds`, already wired to the mute toggle) instead of building `AVAudioEngine` synthesis. Still zero shipped asset files, far less new infrastructure. Synthesis stays deferred; revisit only if system sounds feel wrong in Phase 1 review.
3. **Stable hashing must be hand-rolled.** Swift's `Hasher`/`hashValue` is seeded randomly per process, so it would break the spec requirement that a given `sessionID` always yields the same crystal. FNV-1a is implemented explicitly in Task 1.

```swift
import Foundation

/// Deterministic seed for a session's crystal.
///
/// Deliberately NOT `hashValue`: Swift seeds `Hasher` randomly per process, so
/// using it would give the same session a different crystal on every launch and
/// break the spec's recomputability guarantee. FNV-1a is stable forever.
public enum CrystalSeed {
    public static func value(for sessionID: String) -> UInt64 {
        var hash: UInt64 = 0xcbf29ce484222325
        for byte in sessionID.utf8 {
            hash ^= UInt64(byte)
            hash = hash &* 0x100000001b3
        }
        return hash
    }
}

/// Geometry parameters for one crystal. Derived, never stored.
public struct CrystalForm: Equatable, Sendable {
    /// Per-facet radius multipliers, walking the silhouette clockwise.
    public let facets: [Double]
    /// Rotation of the whole silhouette, radians.
    public let tilt: Double
    /// Vertical stretch. 1.0 is round; below 1 is squat, above is tall.
    public let elongation: Double

    public init(facets: [Double], tilt: Double, elongation: Double) {
        self.facets = facets
        self.tilt = tilt
        self.elongation = elongation
    }

    /// Growth stage 0...6 from elapsed run seconds.
    /// `floor(log2(1 + duration / 30))`, so stage 6 lands at ~31.5 minutes.
    public static func stage(forDuration seconds: TimeInterval) -> Int {
        guard seconds > 0 else { return 0 }
        let value = Foundation.log2(1.0 + seconds / 30.0)
        return min(6, max(0, Int(value.rounded(.down))))
    }

    public static func make(seed: UInt64, stage: Int) -> CrystalForm {
        var rng = SplitMix64(state: seed)
        let clampedStage = min(6, max(0, stage))
        // 3 facets at stage 0 growing to 9 at stage 6.
        let facetCount = 3 + clampedStage
        let facets = (0..<facetCount).map { _ in
            0.55 + rng.nextUnitDouble() * 0.45
        }
        let tilt = (rng.nextUnitDouble() - 0.5) * 0.7
        let elongation = 0.75 + rng.nextUnitDouble() * 0.6
        return CrystalForm(facets: facets, tilt: tilt, elongation: elongation)
    }
}

/// Small deterministic PRNG so the same seed always walks the same sequence.
struct SplitMix64 {
    private var state: UInt64

    init(state: UInt64) {
        self.state = state
    }

    mutating func next() -> UInt64 {
        state = state &+ 0x9e3779b97f4a7c15
        var z = state
        z = (z ^ (z >> 30)) &* 0xbf58476d1ce4e5b9
        z = (z ^ (z >> 27)) &* 0x94d049bb133111eb
        return z ^ (z >> 31)
    }

    /// Uniform in 0..<1.
    mutating func nextUnitDouble() -> Double {
        Double(next() >> 11) * (1.0 / 9_007_199_254_740_992.0)
    }
}
```

```swift
import Foundation

/// One session's crystal. Geometry is derived from the sessionID seed and the
/// current stage — never persisted, always recomputable.
public struct GeodeCrystal: Equatable, Sendable {
    public let sessionID: String
    public let tool: AgentTool
    public let startedAt: Date
    /// Wall-clock seconds spent frozen, excluded from growth.
    public var frozenSeconds: TimeInterval
    public var frozenSince: Date?
    public var stallCount: Int
    public var stage: Int
    public var isSet: Bool
    public var isFractured: Bool
    /// Last event timestamp, used to pick which crystal the pill displays.
    public var updatedAt: Date

    public var isFrozen: Bool {
        frozenSince != nil
    }

    public var form: CrystalForm {
        CrystalForm.make(seed: CrystalSeed.value(for: sessionID), stage: stage)
    }
}

/// Pure reducer over `AgentEvent`. Mirrors the project rule that session
/// mutation lives in exactly one place — nothing else may mutate crystals.
public struct GeodeState: Equatable, Sendable {
    private var crystalsBySessionID: [String: GeodeCrystal] = [:]

    public init() {}

    public func crystal(id: String) -> GeodeCrystal? {
        crystalsBySessionID[id]
    }

    /// The crystal the closed pill should render, or nil.
    /// Stalled sessions win — the freeze carries the alert.
    public var displayed: GeodeCrystal? {
        let live = crystalsBySessionID.values.filter { !$0.isSet }
        let stalled = live.filter(\.isFrozen)
        let pool = stalled.isEmpty ? live : stalled
        return pool.max { lhs, rhs in
            if lhs.updatedAt == rhs.updatedAt {
                return lhs.sessionID < rhs.sessionID
            }
            return lhs.updatedAt < rhs.updatedAt
        }
    }

    public mutating func apply(_ event: AgentEvent) {
        switch event {
        case let .sessionStarted(payload):
            crystalsBySessionID[payload.sessionID] = GeodeCrystal(
                sessionID: payload.sessionID,
                tool: payload.tool,
                startedAt: payload.timestamp,
                frozenSeconds: 0,
                frozenSince: payload.initialPhase.requiresAttention ? payload.timestamp : nil,
                stallCount: 0,
                stage: 0,
                isSet: false,
                isFractured: false,
                updatedAt: payload.timestamp
            )

        case let .activityUpdated(payload):
            guard var crystal = crystalsBySessionID[payload.sessionID] else { return }
            if payload.phase.requiresAttention {
                if crystal.frozenSince == nil {
                    crystal.frozenSince = payload.timestamp
                    crystal.stallCount += 1
                }
            } else {
                crystal.frozenSeconds += frozenElapsed(of: crystal, upTo: payload.timestamp)
                crystal.frozenSince = nil
            }
            crystal.updatedAt = payload.timestamp
            crystalsBySessionID[payload.sessionID] = crystal

        case let .permissionRequested(payload):
            freeze(payload.sessionID, at: payload.timestamp)

        case let .questionAsked(payload):
            freeze(payload.sessionID, at: payload.timestamp)

        case let .actionableStateResolved(payload):
            guard var crystal = crystalsBySessionID[payload.sessionID] else { return }
            crystal.frozenSeconds += frozenElapsed(of: crystal, upTo: payload.timestamp)
            crystal.frozenSince = nil
            crystal.updatedAt = payload.timestamp
            crystalsBySessionID[payload.sessionID] = crystal

        case let .sessionCompleted(payload):
            guard var crystal = crystalsBySessionID[payload.sessionID] else { return }
            crystal.frozenSeconds += frozenElapsed(of: crystal, upTo: payload.timestamp)
            crystal.frozenSince = nil
            crystal.stage = CrystalForm.stage(
                forDuration: growthSeconds(of: crystal, upTo: payload.timestamp)
            )
            crystal.isSet = true
            crystal.isFractured = payload.isInterrupt == true
            crystal.updatedAt = payload.timestamp
            crystalsBySessionID[payload.sessionID] = crystal

        case .jumpTargetUpdated,
             .sessionMetadataUpdated,
             .claudeSessionMetadataUpdated,
             .geminiSessionMetadataUpdated,
             .openCodeSessionMetadataUpdated,
             .cursorSessionMetadataUpdated:
            break
        }
    }

    /// Recompute growth stages. Called on a timer by the app layer.
    public mutating func advance(to now: Date) {
        for (id, crystal) in crystalsBySessionID where !crystal.isSet {
            var updated = crystal
            updated.stage = CrystalForm.stage(
                forDuration: growthSeconds(of: crystal, upTo: now)
            )
            crystalsBySessionID[id] = updated
        }
    }

    /// Drop crystals for sessions no longer tracked, so state cannot grow without bound.
    public mutating func prune(keeping liveSessionIDs: Set<String>) {
        crystalsBySessionID = crystalsBySessionID.filter { liveSessionIDs.contains($0.key) }
    }

    private mutating func freeze(_ sessionID: String, at timestamp: Date) {
        guard var crystal = crystalsBySessionID[sessionID], crystal.frozenSince == nil else { return }
        crystal.frozenSince = timestamp
        crystal.stallCount += 1
        crystal.updatedAt = timestamp
        crystalsBySessionID[sessionID] = crystal
    }

    private func frozenElapsed(of crystal: GeodeCrystal, upTo now: Date) -> TimeInterval {
        guard let since = crystal.frozenSince else { return 0 }
        return max(0, now.timeIntervalSince(since))
    }

    /// Elapsed wall clock minus all frozen time — growth only accrues while running.
    private func growthSeconds(of crystal: GeodeCrystal, upTo now: Date) -> TimeInterval {
        let wall = max(0, now.timeIntervalSince(crystal.startedAt))
        let frozen = crystal.frozenSeconds + frozenElapsed(of: crystal, upTo: now)
        return max(0, wall - frozen)
    }
}
```

```swift
import SwiftUI
import OpenIslandCore

/// Faceted crystal silhouette. Facet radii, tilt, and elongation all come from
/// the session's derived `CrystalForm`, so the same session always draws the same
/// outline at a given stage.
struct GeodeCrystalShape: Shape {
    let form: CrystalForm

    func path(in rect: CGRect) -> Path {
        var path = Path()
        guard form.facets.count >= 3 else { return path }

        let center = CGPoint(x: rect.midX, y: rect.midY)
        let radius = min(rect.width, rect.height) / 2
        let step = (2 * Double.pi) / Double(form.facets.count)

        for (index, multiplier) in form.facets.enumerated() {
            let angle = form.tilt + step * Double(index)
            let point = CGPoint(
                x: center.x + CGFloat(cos(angle) * multiplier) * radius,
                y: center.y + CGFloat(sin(angle) * multiplier * form.elongation) * radius
            )
            if index == 0 {
                path.move(to: point)
            } else {
                path.addLine(to: point)
            }
        }
        path.closeSubpath()
        return path
    }
}

/// One crystal at pill scale. Frozen crystals desaturate to matte grey — that
/// state change is the notification channel, so it must be unmistakable.
struct GeodeCrystalView: View {
    let crystal: GeodeCrystal
    var size: CGFloat = 18

    private var tint: Color {
        if crystal.isFrozen {
            return V6Palette.paper.opacity(0.30)
        }
        return Color(hex: crystal.tool.brandColorHex) ?? V6Palette.paper
    }

    var body: some View {
        GeodeCrystalShape(form: crystal.form)
            .fill(tint)
            .overlay {
                if crystal.isFractured {
                    GeodeFractureOverlay()
                        .stroke(V6Palette.ink.opacity(0.85), lineWidth: 1)
                }
            }
            .frame(width: size, height: size)
            .animation(.easeInOut(duration: 0.35), value: crystal.isFrozen)
            .animation(.easeOut(duration: 0.9), value: crystal.stage)
    }
}

/// A single cleave line across the silhouette. One line reads better than a
/// spider-web at 18pt.
private struct GeodeFractureOverlay: Shape {
    func path(in rect: CGRect) -> Path {
        var path = Path()
        path.move(to: CGPoint(x: rect.minX + rect.width * 0.18, y: rect.minY + rect.height * 0.72))
        path.addLine(to: CGPoint(x: rect.midX, y: rect.midY))
        path.addLine(to: CGPoint(x: rect.maxX - rect.width * 0.22, y: rect.minY + rect.height * 0.24))

    }
```
